# Coffee Sales Analysis

### Project Overview

This project presents a coffee sales dataset transformed into a clean and interactive dashboard. The dashboard allows users to explore sales data through various charts and visualizations, including sales by period, roast type, loyalty card ownership, and coffee size. By using the interactive slicers, users can dynamically filter the data to view sales trends, top customers, and sales by country, providing actionable insights for business decision-making.

### Data Sources

Coffee Sales Data: The primary dataset used for this analysis is the "coffeeSales-RawData.xlsx" file, containing detailed information about orders, customers and product. 

### Tools

- Excel - Data Cleaning, Data Analysis, Creating Reports

### Exploratory Data Analysis 

EDA involved exploring the sales data to answer key question, such as:
- What are the total sales over time?
- How are the sales distributed by country?
- Who are the top 5 customers?

These insights can be further filtered dynamically using slicers by period, loyalty card ownership, and coffee size, allowing a more detailed and interactive analysis.
